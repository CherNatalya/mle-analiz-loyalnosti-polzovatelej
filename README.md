# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта
Проект посвящен исследованию поведения пользователей на платформе Яндекс Афиша. 
Цель — выявить признаки, связанные с возвращением пользователей (совершением повторных заказов), 
и сформулировать рекомендации для отдела маркетинга.

## Структура проекта
- `src/processing.py` — класс `DataProcessor` для загрузки, предобработки, создания профиля и анализа.
- `main.py` — главный скрипт, запускающий весь пайплайн и выводящий отчет в терминал.
- `data/` — папка для сырых данных (не хранится в репозитории).
- `.env.example` — шаблон для переменных окружения.

## Инструкция по запуску
1. Склонируйте репозиторий.
2. Создайте и активируйте виртуальное окружение:
   ```
   python -m venv venv
   source venv/Scripts/activate  # для Windows
   # или source venv/bin/activate для Mac/Linux
   ```
3. Установите зависимости:
    ```
    pip install -r requirements.txt
    ```
4. Создайте файл `.env` (скопируйте `.env.example` и заполните реальные доступы к базе данных).

5. Положите в папку `data/` файлы `afisha_purchases.csv` (выгрузка заказов) и `final_tickets_tenge_df.csv` (курс валют). При наличии доступа к БД скрипт может выгрузить данные сам.

6. Запустите проект одной командой:
    ```
    python main.py
    ```

## Итоги анализа и бизнес-рекомендации

### Ключевые выводы
- Пользователи: средняя выручка на пользователя — 551.91 руб. Доля пользователей с 2+ заказами (Retention) — 61.62%.
- Успешные «точки входа» (доля возвратов выше средней):
  - Мероприятия: выставки (64.68%), театр (63.86%), концерты (62.04%).
  - Устройства: desktop (63.86%) против mobile (61.15%).
  - Регионы: Шанырский (69.66%), Светополянский (66.09%), Широковская (64.82%), Североярская (64.33%).
- Выручка: медианный чек у вернувшихся пользователей выше на 116.73 руб. (388.72 руб. против 505.45 руб.), хотя средние чеки почти равны.
- Гипотезы: Гипотеза о том, что начавшие со спорта возвращаются чаще концертов — опровергнута (55.19% против 62.04%). Размер региона не определяет возврат.

### Ограничения
Признаки avg_days_between и avg_revenue_rub известны только после нескольких покупок. Их нельзя использовать для прогноза возврата в момент первого заказа. Признаки первого заказа (тип, устройство, регион) дают слабую связь (phi_k 0.03–0.10).

### Рекомендации для маркетинга
1. Повышать медианный чек (предлагать сопутствующие товары), а не гнаться за разовыми дорогими заказами.
2. Удерживать успешные «точки входа»: театр, выставки, концерты, пользователи с desktop, а также регионы Шанырский, Светополянский, Широковская и Североярская области.
3. Для массового сегмента mobile + концерты/«другое» тестировать промо на второй заказ и рекомендации мероприятий из смежных категорий.
4. Для сегментов с низкой долей возврата (спорт, ёлки) предлагать смежные жанры, а не полагаться только на повторные продажи в той же категории.
